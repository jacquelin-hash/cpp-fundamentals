# C++ Fundamentals

This repository contains my C++ practice exercises and examples.

## Topics

```
- Variables and data types
- Conditional statements
- Loops
- Functions
- Arrays
- Vectors
- Object-oriented programming
```

## Compile and Run

Compile a file using:
```bash
g++ path/to/file.cpp -o program
```

Run
```bash
./program
```

Example 
```bash
g++ begineer/loops.cpp -o loops
./loops
```
